# days.json: the Graveyard Keeper 2 week (the "Dias" tab)

`data/days.json` describes the six-day week shown on the HUD day wheel and what is gated by each weekday.
It is generated by `scripts/build_days.py` (stdlib only). Built 2026-10-30 against game version 1.011 texts.

## Regenerate

```sh
python3 -I scripts/build_days.py                    # writes data/days.json (meta.built = today)
python3 -I scripts/build_days.py --date 2026-10-30  # same, with a pinned date (byte-identical output)
python3 -I scripts/build_days.py --check            # build and validate only, writes nothing
```

Inputs: `data/game-texts/gk2_textos.json` (required), `data/gk2.json` (only to check the item ids in `events[].items`).
The script stops with a list of errors if a cited game-text key is missing, if the main key of a day-gated event does not show that day's glyph, if an item id is unknown, or if the day glyphs in the texts are not exactly the six expected ones.

**Built from the game texts on every run:** the six day ids (from `<sprite name="day_X">`), the official en/pt sin names (from the portal fragment names `portal_stone_X`), every game text that shows each day's glyph (`days[].mentions`), the official quote attached to each event (`events[].quote`), and the official title of the quest that unlocks it (`events[].unlock`).

**Hand-written in the script, with sources:** the week order (`ORDER`), the glyph descriptions and colours (`DAY_ART`), and the short en/pt event lines (`EVENTS`). To add or fix an event, edit `EVENTS` and re-run.

Icons: `data/icons/day__<id>.png` (6 files, 100x100) are the official HUD day medallions. They were copied from wikily's media CDN (`day_<id>.png`, raw copies in `data/raw/days/`). The script does not touch them. The sprite sheet still has to be regenerated so the page gets the `day:<id>` ids.

## Schema

```jsonc
{
  "meta": {
    "schema": 1, "week_length": 6,
    "order": ["gluttony","sloth","lust","envy","pride","wrath"],
    "order_confidence": "likely",          // official | likely | guess
    "order_note": {"en","pt"},
    "wheel": {...},                         // direction, current marker, highlight, centre picture
    "greed": {...},                         // why there is no 7th day
    "lore_note": {...}, "sources": [...], "credits": "...", "legend": {...},
    "built": "2026-10-30", "notes": {"pt","en"}
  },
  "days": [{
    "id": "sloth", "order": 1,
    "sin": {"en":"Sloth","pt":"Preguiça"}, "sin_tr": "official",
    "name": {"en":"Day of Sloth","pt":"Dia da Preguiça"}, "tr": "likely",
    "sprite": "day_sloth",                  // the game's own sprite name for the glyph
    "glyph": "crescent moon, gold on a blue disc", "glyph_pt": "...", "color": "#15619f",
    "prev": "gluttony", "next": "lust",
    "events": [{
      "kind": "npc|merchant|church|battle|quest|event|other",
      "en": "...", "pt": "...",             // short, phone-sized
      "tr": "machine",                      // written for this app; the official wording is in `quote`
      "who": "Linda", "who_pt": "Linda",    // official pt names (Herbert = Norberto, Davy the Dagger = Orlando, Olha a Faca...)
      "source": "game-text:<key> | wikily:<dataset or page>/<key> | web:<url>",
      "also": ["other sources"],
      "confidence": "high|medium|low",
      "items": ["ids in data/gk2.json"],
      "unlock": {"key","en","pt","tr"} | null,   // the quest (official title) after which this applies
      "detail": {"en","pt"} | null,              // optional longer text
      "quote": {"key","en","pt"} | null          // official game text; the day glyph is replaced by the sin name
    }],
    "mentions": [{"key","en","pt"}]          // every game text showing this day's glyph
  }]
}
```

`tr`: `official` means verbatim game text. `likely` means built from official words (for example "Dia da" + the official sin name). `machine` means written for this app, not taken from the game.
`confidence`: `high` means a game text states it (usually wikily too). `medium` means only wikily or a web guide says it. `low` means a single unverified guide.

In `quote`, the glyph is replaced by the sin name, which can read oddly in pt ("todo Luxúria"), because the game shows an icon there. The UI can draw the glyph instead.

## What is confirmed and what is assumed

**Confirmed by the game texts (high):**
- The week has six days. Greed is the seventh sin and portal fragment, but it has no day. The Old God says "there's only six days here" and that "six looks better on the wheel of time" (`113_sewers_god_34/35`). The game uses only six day glyphs: `day_gluttony`, `day_sloth`, `day_lust`, `day_envy`, `day_pride`, `day_wrath`. There is no `day_greed`.
- The game never writes a day's name, only the glyph. The official pt sin names come from the portal fragments: Gula, Preguiça, Luxúria, Inveja, Orgulho, Ira. The orbs also say "Ira", but the perk text says "Fúria".
- **Gluttony:** PR Machine loads.
- **Sloth:** battles; the bell rings in the morning and the zombies withdraw.
- **Lust:** the trade ship and the Trademaster's new goods; Linda takes Green Scrolls; Davy the Dagger takes looter orders; the quest steps in High Price and Concept for a Concert.
- **Envy:** resurrection (the lightning storm); the Goddess's Blue Crystals.
- **Pride:** town orders; the traders' weekly Likes caps reset.
- **Wrath:** sermon/Mass; Agatha's corpse-delivery setting; the Nun's early visits.
- Prayer for Storms (the "God of the storms" buff) lets you resurrect at any time (`buff_storm_d`).

**From wikily only (medium):** the any-day battle exceptions, the red-banner window, the Resurrection Lab recharging at the end of Lust, the Town Warehouse payout and repeatable orders on Pride, the PR Machine program counting down at the end of Wrath, and the Blue Crystal pile of 4.

**Low:** the Plague Doctor gives 2 free zombies on Envy. Only roonby.com and prodigygamers.com say this.

**Week order (`likely`, not from game data):** Gluttony, Sloth, Lust, Envy, Pride, Wrath. wikily's calendar page numbers them "1 of 6" ... "6 of 6", and gamer-guides.com and gamebrief.net agree. roonby.com and prodigygamers.com give the same cycle but start counting at Wrath. So the cycle is well supported, but which day is "first" is a convention. This is not the GK1 order. GK1 facts were not used.

**Unknown / open:**
- Which weekday a new game starts on, and how the game's day counter (`environmentData.Day`, shown by the "Date Time and Counter" mod) maps to a weekday. The UI should let the player tap the glyph they see, not compute it.
- The wheel direction. gamer-guides says the medallions run clockwise in the order above, with the current one standing out of the ring. wikily says the wheel lights today's and tomorrow's glyph. Neither was checked against a screenshot.
- The glyphs are described from the official icons. They look like astrological signs: Sloth is a crescent Moon, Lust is ♀ Venus, Pride is the Sun, Wrath is ♂-like Mars, and the Greed fragment is ♄ Saturn. Gluttony (ψ/trident) and Envy (horned circle) are less clear. This is an interpretation, not a source.
- In the story, the days are "changing places" (`158_astrologer_palace_help_6`). No source says the order changes during play.
